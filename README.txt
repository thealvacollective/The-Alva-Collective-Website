THE ALVA COLLECTIVE WEBSITE

Upload index.html, styles.css, script.js and the assets folder to the ROOT of your GitHub repository.

GitHub Pages:
1. Repository > Settings > Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Save

Important before launch:
- The contact form currently points to info@thealvacollective.com and opens the visitor's email app. Change that email in index.html if needed.
- The abstract visual blocks are placeholders. They can later be replaced with licensed/original interior and product photography.
- After the GitHub preview is working, connect thealvacollective.com as the custom domain.
